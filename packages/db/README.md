# @next-js-template/db

Database package: [Drizzle ORM](https://orm.drizzle.team) on PostgreSQL (`pg` driver).

- `src/index.ts` exports `db` (shared client), `createDb()` and `generateId()`
- `src/schema/` holds the tables: `auth` (generated by Better Auth), `order`, `esim`
- `src/migrations/` holds the SQL migrations generated by drizzle-kit

## Usage

```ts
import { db, generateId } from "@next-js-template/db";
import { order } from "@next-js-template/db/schema/order";
```

## Scripts

Run these from the repo root. `drizzle.config.ts` reads `DATABASE_URL` from `apps/web/.env`.

| Command               | What it does                              |
| --------------------- | ----------------------------------------- |
| `bun run db:start`    | Start local Postgres (docker compose)     |
| `bun run db:generate` | Generate a migration from schema changes  |
| `bun run db:migrate`  | Apply migrations                          |
| `bun run db:push`     | Push the schema without a migration (dev) |
| `bun run db:studio`   | Open Drizzle Studio                       |
| `bun run db:stop`     | Stop local Postgres                       |

Don't edit `src/schema/auth.ts` by hand. Regenerate it with `bun run auth:generate`.
